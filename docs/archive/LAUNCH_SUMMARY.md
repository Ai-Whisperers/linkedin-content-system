## 🎯 Content Generation Tips

### Use the Template Format

Every post should follow this structure (see example post 001):

```markdown
# Post XXX: [Title]

## Post Metadata
[Number, dates, type, audience, status]

## Post Copy (Final Version)
[120-180 words, ready to paste into LinkedIn]

## Quality Checklist
[All checks completed]

## Source Context
[Where the content came from]
```

### Quality Checklist (Every Post)

- [ ] 120-180 words
- [ ] No fake metrics
- [ ] Real examples or authentic philosophy
- [ ] 4 hashtags (2 broad + 2 niche)
- [ ] Max 2 emojis (or 0)
- [ ] Conversational CTA
- [ ] Matches brand voice
- [ ] Provides clear value

### Approval Process

1. Generate post using template
2. Run through quality checklist
3. Move to appropriate folder:
   - ✅ **approved/** if ready
   - ⚠️ **needs-revision/** if close but needs edits
   - ❌ **rejected/** if doesn't meet standards
