## Slide 3: Framework

### Title
```
The 4-Lane Triage Model
```

### Content
```
1. Auto-Resolve → Password resets, FAQs
2. Low-Touch → Simple requests, 1-step fixes
3. Complex → Multi-step, requires judgment
4. Escalate → Critical, senior attention
```

### Visual Notes
- Diagram: 4 horizontal lanes or swim lanes
- Each lane labeled with category + example
- Flow arrows from "Incoming Tickets" to 4 lanes
- Color-coded lanes (green → yellow → orange → red)

```
Setup in 20 Minutes
```

### Content

```
3. Connect to ticket system API
4. Test with 50 new tickets
5. Deploy to production triage lane
```

### Visual Notes
- Numbered checklist format
- Clock icon emphasizing "20 minutes"
- Simple, step-by-step layout
- Tools mentioned: CSV, API, Classifier (icons optional)

## Slide 6: Mistakes (What We Got Wrong)

### Title
```
3 Things We Got Wrong
```

### Content
```

2. Skipped training → Agent misrouted 20% of tickets initially
3. No feedback loop → Added human review for edge cases
```

### Visual Notes
- Red X icons or cautionary symbols
- Honest, conversational tone
- Strike-through text for "wrong" approach, arrow to fix
