## How to Document Each Repo

### Template Structure (30-40 minutes per repo)

Create: `context/repos/repo-[name].md`

**Required sections:**
1. **Overview** (2-3 sentences)
   - What problem does it solve?
   - Who is it for?

2. **Key Features** (3-5 bullet points)
   - Main capabilities
   - Technical highlights
   - Unique aspects

3. **Tech Stack** (1-2 sentences)
   - Primary languages
   - Key frameworks/libraries
   - Infrastructure

4. **Metrics/Results** (if available)
   - Performance numbers
   - Time/cost savings
   - User impact

5. **Challenges Overcome** (2-3 bullet points)
   - Technical problems solved
   - Design decisions
   - Lessons learned

6. **Future Plans** (optional)
   - Planned features
   - Known limitations
   - Next steps

**Example:** See existing `context/repos/repo-agentic-schemas.md`
