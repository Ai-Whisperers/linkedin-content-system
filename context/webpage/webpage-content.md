#### Course 2: Agentic Architectures (Intelligent Systems)

**Target Audience:**
- Developers and software engineers
- AI engineers and ML practitioners
- Technical leads and architects
- Anyone building agentic AI systems

**Topics Covered:**
- **20 foundational agentic design patterns:**

  **Core Patterns (1-10):**
  1. Prompt Chaining - Sequential processing through connected prompts
  2. Routing - Intelligent request distribution based on content
  3. Parallelization - Concurrent execution for efficiency
  4. Reflection - Self-evaluation and iterative improvement
  5. Tool Use - External API and function integration
  6. Planning - Multi-step task decomposition
  7. Multi-Agent Collaboration - Coordinated agent teamwork
  8. Memory Management - Context retention and retrieval
  9. Learning & Adaptation - Continuous improvement from feedback
  10. Goal Setting & Decomposition - Breaking down complex objectives

  **Reliability Patterns (11-15):**
  11. Exception Handling - Graceful failure management
  12. Human-in-the-Loop - Human oversight and approval gates
  13. Retrieval (RAG) - Knowledge base integration
  14. Inter-Agent Communication - Message passing and coordination
  15. Resource-Aware Optimization - Efficiency and cost management

  **Reasoning Patterns (16-20):**
  16. Reasoning Techniques - Chain-of-Thought (CoT), Tree-of-Thought (ToT)
  17. Evaluation & Monitoring - Performance tracking and metrics
  18. Guardrails & Safety - Constraint enforcement and safety checks
  19. Prioritization & Scheduling - Task ordering and resource allocation
  20. Exploration & Discovery - Learning through experimentation

- Multi-agent systems architecture
- Pattern composition and dependencies
- Trade-off analysis (cost, latency, reliability)
- Implementation strategies and best practices
- Graph-structured framework approach

**Learning Outcomes:**
- Choose the right agentic pattern for any use case
- Build reliable multi-agent systems
- Understand pattern trade-offs and when to use each
- Implement production-ready agentic workflows
- Compose multiple patterns for complex systems

**Based On:**
AI-Whisperers' Agentic Schemas repository (https://github.com/Ai-Whisperers/agentic-schemas)

**Key Value:**
- Plain-English explanations accessible to all skill levels
- Trade-off analysis for informed decision-making
- Practical implementation guidance with real examples
- Interactive D3.js visualizations of pattern relationships
