# Repository: Agentic Schemas

**URL:** https://github.com/Ai-Whisperers/agentic-schemas
**Status:** Published (Educational Resource)
**Primary Language:** Documentation + JavaScript (visualization)
**Last Updated:** October 8, 2025
**Type:** Thought Leadership & Educational

## Purpose

Models 20 foundational agentic design patterns as an interconnected knowledge graph. A compact, practical guide to building reliable AI agents.

**Use Case:** Educational resource for engineers building multi-agent systems. Showcases AI-Whisperers' technical expertise and thought leadership.

---

## Key Features

**1. 20 Documented Patterns**
- Complete catalog of agentic design patterns
- Organized by layer (Core, Reliability, Reasoning)
- Plain-English explanations
- Trade-off analysis for each pattern

**2. Knowledge Graph Structure**
- Patterns modeled as interconnected graph
- Weighted edges show pattern dependencies (0.60–0.95)
- Hub, authority, and bridge node classifications
- Visualizes relationships between patterns

**3. Interactive Visualization**
- D3.js graph visualization
- Interactive exploration
- Mermaid diagrams for documentation
- Visual pattern relationships

**4. Structured JSON Schemas**
- Machine-readable pattern definitions
- Consistent schema across all patterns
- Integration-ready format
- Extensible structure

**5. Practical Guidance**
- When to use each pattern
- Trade-offs (cost, latency, failure modes)
- Composition strategies
- Real-world use cases

## The 20 Agentic Patterns

### Core Patterns (1-10)

1. **Prompt Chaining**
   - Sequential task decomposition
   - Output of one step feeds next
   - Simple orchestration

2. **Routing**
   - Dynamic path selection
   - Conditional logic
   - Classifier-based decisions

3. **Parallelization**
   - Concurrent task execution
   - Reduce latency
   - Independent operations

4. **Reflection**
   - Self-evaluation and improvement
   - Iterative refinement
   - Quality enhancement

5. **Tool Use**
   - External API integration
   - Function calling
   - Action capabilities

6. **Planning**
   - Multi-step strategy creation
   - Goal decomposition
   - Adaptive plans

7. **Multi-Agent Collaboration**
   - Multiple agents working together
   - Specialized roles
   - Coordinated actions

8. **Memory Management**
   - Context retention
   - State persistence
   - Long-term knowledge

9. **Learning & Adaptation**
   - Continuous improvement
   - Feedback loops
   - Pattern recognition

10. **Goal Setting**
    - Objective definition
    - Success criteria
    - Autonomous targeting

### Reliability Patterns (11-15)

11. **Exception Handling**
    - Error recovery
    - Graceful degradation
    - Retry strategies

12. **Human-in-the-Loop**
    - Manual approval gates
    - Oversight mechanisms
    - Trust building

13. **Retrieval/RAG**
    - Retrieval Augmented Generation
    - Knowledge base integration
    - Context enhancement

14. **Inter-Agent Communication**
    - Message passing
    - Coordination protocols
    - Information sharing

15. **Resource-Aware Optimization**
    - Cost management
    - Latency optimization
    - Resource allocation

### Reasoning Patterns (16-20)

16. **Reasoning Techniques (CoT/ToT)**
    - Chain-of-Thought
    - Tree-of-Thoughts
    - Step-by-step logic

17. **Evaluation & Monitoring**
    - Performance tracking
    - Quality metrics
    - Observability

18. **Guardrails & Safety**
    - Constraint enforcement
    - Safety boundaries
    - Risk mitigation

19. **Prioritization**
    - Task ranking
    - Resource allocation
    - Critical path analysis

20. **Exploration & Discovery**
    - Novel approach testing
    - Breadth-first search
    - Innovation capability

**Challenges:**

- Balancing depth vs. accessibility
- Visualizing complex relationships
- Maintaining consistency across 20 patterns
