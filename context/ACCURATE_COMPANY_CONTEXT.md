## Real Projects (Verified from GitHub)

### 1. Work Hours Automated Reports ⭐ (Most Recent)

**Repository:** https://github.com/Ai-Whisperers/work-hours-automated-reports

**What it does:**
Automates time tracking reconciliation between Clockify and Azure DevOps. Intelligently matches time entries with work items and generates comprehensive reports.

**Technical Stack:**
- Backend: Python 3.11+, FastAPI
- Frontend: Next.js 18+
- Architecture: Hexagonal (ports & adapters)
- Deployment: Docker, docker-compose
- Testing: pytest
- Code Quality: Black formatter

**Key Features:**
- Intelligent pattern matching (recognizes `#12345`, `ADO-12345`, `WI:12345`, etc.)
- Activity tracking (mouse/keyboard monitoring, GitHub commits)
- Multi-format reporting (Excel, HTML, JSON, PDF)
- Web dashboard with real-time reporting
- Clean architecture (SOLID principles)

**Status:** Active development (32 commits, last updated Oct 21, 2025)
